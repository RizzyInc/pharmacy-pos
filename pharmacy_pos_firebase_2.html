Connect Firebase — One-time Setup

Do this once. Your config is saved in the browser.

1
Create a free Firebase project
Go to console.firebase.google.com → Add project → name it merit-pharmacy-2 → disable Google Analytics → Create project
2
Enable Authentication (Email/Password)
Build → Authentication → Get started → Sign-in method → Email/Password → Enable → Save
Then go to Users → Add user and create accounts for each staff member (e.g. admin@meritpharmacy.com).
3
Enable Realtime Database
Build → Realtime Database → Create database → choose region → Start in test mode → Enable
Then go to the Rules tab and paste:
{ "rules": { ".read": "auth != null", ".write": "auth != null" } }
4
Get your Web App config
Project Settings (⚙️) → Your apps → </> Web → Register app → copy the firebaseConfig values into the fields below.

🔑 Paste your Firebase config
